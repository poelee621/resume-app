> 解决 Cloudflare workers.dev 在国内手机打不开的问题（真 AI + 真支付在国内可用）

## 一、本地打包

```bash
cd C:\Users\21474\WorkBuddy\appwork\resume-cap\server
tar -acf resume-api.zip index.mjs
```

**zip 根目录直接放 `index.mjs` 一个文件**（不要套文件夹，不要带 README / pem）。

## 二、阿里云控制台创建函数

1. 打开 https://fcnext.console.aliyun.com
2. 左侧「函数管理」→「函数列表」→ 右上角「**+ 创建函数**」
3. 选 "**Web 函数**" tab（不是事件函数/任务函数）
4. 关键配置：

| 字段 | 填什么 | 备注 |
|---|---|---|
| 函数名 | `resume-api` | |
| 区域 | **华东1（杭州）cn-hangzhou** | |
| **运行环境** | **自定义运行时 / Node.js 20** |**关键**：容器模式，代码自己起 HTTP Server |
| 实例类型 | 弹性实例 | |
| 规格 | 最小档 0.15 vCPU / 0.15 GB / 512 MB | |
| **最小实例数** | **0** | 0=按需启动，省钱；1=保活按秒扣费 |
| 单实例并发度 | 20 | |
| 代码上传方式 | **通过 ZIP 包上传代码** | 不要用示例代码 |
| **启动命令** | **`node index.mjs`** | 不要 `npm run start`（没 package.json）|
| 监听端口 | `9000` | 默认 |
| 执行超时 | `60` 秒 | |

点「创建」→ 等待上传 + 部署完成。

## 四、拿调用 URL

Web 函数创建后会自动分配 URL，**在函数详情页右上角「调用方式 / 触发器」里能看到**，长这样：

```
https://resume-api-cn-xxxxxxxxxxxx.fc.aliyuncs.com/
```

或者函数详情页「配置」→「访问地址」/ 触发器标签页。

**把这个 URL 复制发给 AI，我接进前端**。

## 五、验证（可选但推荐）

浏览器直接访问：

```
https://你的地址/health
→ 看到 {"ok":true,"ts":..., "service":"resume-api-aliyun-fc"} 即成功
```
