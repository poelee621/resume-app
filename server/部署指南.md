# 阿里云函数计算（FC）部署指南

> 解决 Cloudflare workers.dev 在国内手机打不开的问题（真 AI + 真支付在国内可用）

## 一、创建函数

1. 打开 https://fcnext.console.aliyun.com （函数计算 FC 3.0）
2. 左侧「服务及函数」→ **创建服务**
   - 名称：`resume-api`
   - 地域：选**华东1（杭州）**或离你近的
   - 开通日志（可选，免费额度内）
3. 进入服务 → **创建函数**
   - 创建方式：**内置运行时创建**
   - 运行环境：**Node.js 20**（或 18）
   - 代码上传方式：**上传代码 ZIP** 或 **通过文件夹上传**
     - 把本目录的 `index.mjs` 打成 zip 上传（单文件，无依赖）
   - 请求处理程序（入口）：`index.handler`
   - 内存：512 MB / 超时：30 秒（首次可设 60 秒）

## 二、配置环境变量

函数详情 → 「配置」→「环境变量」→ 添加 6 个：

| 变量名 | 值 | 说明 |
|---|---|---|
| `DEEPSEEK_API_KEY` | `sk-74206c8d0468453da8faa2e37fc57420` | DeepSeek key |
| `WX_MCH_ID` | `1117051434` | 商户号 |
| `WX_CERT_SERIAL` | `582EE71F38B03965F32900AF930222993723E8C2` | 证书序列号 |
| `WX_API_V3_KEY` | `LIpo88751996LIpo88751996LIpo8875` | APIv3 密钥 |
| `WX_APP_ID` | `wxde58bc283bad6044` | 公众号 AppID |
| `WX_PRIVATE_KEY` | （apiclient_key.pem 全文，含首尾行）| 商户私钥 |

`WX_PRIVATE_KEY` 注意：**保留真实换行**（阿里云环境变量支持多行文本）。
如果控制台不支持换行，把换行替换成 `\n` 字面量（代码里 `.replace(/\s+/g,"")` 会处理，但 `\n` 字面量不会被去掉——此时需改代码用 `key.replace(/\\n/g,"\n")`）。

## 三、创建 HTTP 触发器

函数详情 → 「触发器」→ **创建触发器**
- 触发器类型：**HTTP 触发器**
- 名称：`resume-http`
- 请求方法：`GET, POST, OPTIONS`
- 认证方式：**无需认证**（前端直连）
- 创建后会得到 URL，类似：
  ```
  https://resume-api-xxxxx.cn-hangzhou.fcapp.run
  ```

## 四、验证

浏览器 / curl 访问：

```bash
# 健康检查
curl https://你的地址/health
# → {"ok":true,"service":"resume-api-aliyun-fc"}

# AI 测试
curl -X POST https://你的地址/chat -H "Content-Type: application/json" \
  -d '{"messages":[{"role":"user","content":"你好"}]}'

# 下单测试（返回 code_url 即为成功）
curl -X POST https://你的地址/pay/create -H "Content-Type: application/json" -d '{"plan":"once"}'
```

## 五、前端接上

把地址填到 `www/index.html` 的：

```js
const AI_WORKER_URL="https://你的地址/";  /* 注意末尾有 / */
```

然后同步到 android/ios 并重新出包：

```bash
cp -r www/* android/app/src/main/assets/public/
cp -r www/* ios/App/App/public/
```

## 六、微信支付回调地址（可选）

支付回调现在**不依赖**（状态靠订单查询 API）。如果要启用回调通知，在商户平台把 `notify_url` 设为：
```
https://你的地址/pay/callback
```
