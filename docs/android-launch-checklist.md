- [ ] 阿里云账号是坡哥/烯冷实名（备案主体与账号实名一致才顺）
- [ ] 准备营业执照原件 + 法人身份证原件（要**现拍**，白色背景人脸核验）

### 1️⃣ 操作步骤（阿里云 ICP 代备案管理系统）
1. 登录阿里云控制台 → 搜「ICP 备案」→ 进入备案系统 → 点「开始备案」
2. 服务类型选 **App**，填 App 名称（AI简历工坊）
3. 主办者信息：填烯冷企业信息（执照自动带出）
4. App 信息：名称 / 图标 / 内容分类（工具-办公效率？按实际选）/ 语言（中文）
5. **添加运行平台：安卓 + iOS 一起勾**（同名一次备案，发一个备案号）
6. 安卓平台填：包名 `com.coldtank.resume` + 签名 MD5（上表）——**建议直接上传 debug/release APK**，阿里云「备案智能助理」自动解析包名/签名，免手填出错
7. iOS 平台填：Bundle ID（`com.coldtank.resume` 同值）+ 证书指纹（暂无 iOS 证书可先只做安卓，iOS 后续变更加平台即可）
8. App 服务域名：登记 `coldtank.cn`（后台实际域名 fcapp.run 是阿里云共享域，登记自己已备案域名即可）
9. 上传资料：营业执照原件拍照（≥200KB JPG/PNG，**不能翻拍手机/电脑里的照片**）
10. 负责人人脸核验：阿里云 App 发链接到手机 → 白墙前实拍
11. 提交初审 → **阿里云 1-2 工作日内电话核验**（保持手机通）
12. 初审过 → 收工信部短信 → **24 小时内完成短信核验**（超时订单作废）
13. 管局审核（最长 ~20 天）→ 通过后收邮件，拿到「App 备案号」

### 2️⃣ 时间线预期
阿里云初审 1-2 工作日 + 管局 5~20 工作日 ≈ **3-22 个工作日**。9/5 提交 → 乐观 9 月中、保守 10 月初。

## 🤖 四、release 签名 APK（CI 已就绪，等你一次操作）

- GitHub repo（public）→ Settings → Secrets and variables → Actions → 新建 2 个 secret：
  - `ANDROID_KEYSTORE_B64` = `~/.resume-keys/ci-secrets/ANDROID_KEYSTORE_B64.txt` 整串
  - `ANDROID_KEYSTORE_PROPERTIES` = `~/.resume-keys/ci-secrets/ANDROID_KEYSTORE_PROPERTIES.txt` 全文
- 加完随便 push → Release 出标题带 **· release** 的 `app-release.apk` 即真签名包
- 下载验证：`keytool -printcert -jarfile app-release.apk | grep SHA1` 应为 `8E:D4:C3:68:...`
