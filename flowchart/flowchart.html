职简 · 微信支付集成流程

用户 → App → 阿里云后端 → 微信支付 APIv3 完整时序
参与者
📱 用户
📲 职简 App
☁️ 后端（阿里云 FC）+ 微信支付
操作顺序
1选择套餐，点击「确认支付」↓ 发起下单请求
2接收订单号，拉起微信收银台 / 展示支付二维码← 返回支付参数
3调用微信支付下单 API
校验签名 → 创建订单← 返回 prepay_id / code_url
4微信内完成付款（指纹/密码确认）↓ 支付完成
5微信支付结果通知回调 → 后端校验并确认订单→ /pay/callback
6App 轮询订单状态→ GET /pay/status
7查询微信订单 API，确认交易成功← trade_state = SUCCESS
8🎉 支付成功提示，自动解锁 Word/PDF 导出会员权益即时生效
安全说明：微信支付 APIv3 双向证书签名校验，订单状态以后端查询微信支付官方 API 为准，回调双重确认，保障资金安全
